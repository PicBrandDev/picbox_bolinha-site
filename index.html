Documentação técnica da PICBOX Bolinha

Máquina A, versão compacta. Dois carros oscilam em trilhos, um acima do outro: o de cima leva a bola de aço num eletroímã e o de baixo leva o anel. O jogador aperta o botão para soltar a bola; se ela passar pelo anel, conta ponto. Um elevador de rosca devolve a bola ao topo. Tudo nesta página sai do CAD do projeto.

        Catálogo de peças impressas

        Todas as peças impressas da versão atual. Novas são as que precisam ser impressas; reaproveitadas já estão impressas desde a R2.2 (o STL fica para reimprimir se quebrar). Massa e horas são estimadas (PETG, 0,2 mm, 4 perímetros, 25%). O STEP de cada peça está na posição de montagem.

        Mesas de impressão

        Só as peças novas, já arrumadas na mesa e sem suporte. A: 260 × 260. B e C: Creality 220 × 220. As 3 impressoras podem trabalhar ao mesmo tempo.

        Regenerar peças, imagens e este site

        O CAD em compacta/cad/maquina/ é a fonte. STL, STEP, mesas, imagens, páginas e este site são derivados. Precisa de Python com CadQuery, manifold3d e PyVista (no Windows, rodar pelo PowerShell).

        cd compacta/cad/maquina
python regerar.py              # checagens, peças, imagens, páginas, STEP e docs/ (~6 min)
python site_publico.py         # só o site: docs/data, docs/img, docs/pagina, docs/picbox
python -m http.server -d ../../../docs 5173    # este site em http://localhost:5173
git subtree push --prefix docs site main      # da raiz: envia docs/ para o site público
